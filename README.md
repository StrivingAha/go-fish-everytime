# 摸鱼监视器：FishEverytime · 人脸隐私守护

一个面向 **Chrome / Microsoft Edge 120 及以上版本**的浏览器扩展。通过摄像头在本机识别使用者，当指定范围内出现陌生人，或使用者离开镜头时，记录并关闭当前浏览页，再切回预先打开的保护标签页。

当前版本：**1.1.1**。采用 Manifest V3；模型与推理运行时随扩展提供，无需构建、无需启动服务器、无需注册账号。

## 功能

| 功能 | 说明 |
| --- | --- |
| 多角度人脸录入 | 正脸、左侧脸、右侧脸、低头、抬头各采集 3 个合格样本；录入时自动跳过不清晰帧，每轮最多等待 20 秒。 |
| 陌生人检测 | 对检测范围内的每张脸分别验证；本人和陌生人同时入镜也会触发保护。 |
| 离席保护 | 未检测到本人时，在设定的容忍时间后触发保护。 |
| 保护标签页 | 开启时提前打开指定网站；触发时关闭当前浏览页，切回原保护标签页，不重新打开、导航或刷新它。再次开启时，配置地址未变且原保护标签页仍在同一窗口，会继续复用。 |
| 检测范围设置 | 支持选择摄像头、拖动框选检测区域或恢复全画面检测；框外人脸不参与判断。 |
| 网址恢复记录 | 本地记录被关闭网页的网址、标题、时间、原因及关闭状态，支持重新打开，最多保留 200 条。 |
| 可调触发延迟 | 陌生人可选立即、0.6 秒、1.2 秒；离席可选立即、1.5 秒、3 秒。 |
| 监测异常保护 | 摄像头断开、检测异常、监测标签页关闭或监测失去响应时触发保护。 |

## Quick Start

### 1. 下载并加载扩展

下载仓库并解压，或克隆仓库。找到包含 **`manifest.json`** 的文件夹。

1. Chrome 打开 `chrome://extensions`，Edge 打开 `edge://extensions`。
2. 开启“开发者模式”。
3. 点击“加载已解压的扩展程序”（部分浏览器显示为“加载解压缩的扩展”）。
4. 选择包含 `manifest.json` 的文件夹。如果仓库保留了 `extension/` 目录，选择该目录；如果本目录的内容直接放在仓库根目录，选择仓库根目录。
5. 点击浏览器工具栏中的 FishEverytime 扩展图标，打开监测页面。可将图标固定到工具栏，便于再次访问。

**无需执行 `npm install`，也无需手动下载模型。请完整保留 `models/` 与 `vendor/` 目录。**

### 2. 录入本人

1. 点击“打开摄像头”，允许浏览器访问摄像头；如有多个设备，可从列表中选择。
2. 保持光照充足，确保画面中只有本人。可在画面上拖动框选检测范围，或使用“全画面检测”。画面未镜像。
3. 按提示依次录入正脸、左侧脸、右侧脸、低头、抬头。建议缓慢转头约 20–40°，保持五官可见，避免完全侧脸或遮挡。
4. 等待每个角度显示 `3/3`。如提示面部过小、光照不足或处于范围边缘，调整后重试。需要重新录入时，点击“删除面部特征”。

### 3. 开启并使用保护

1. 填写完整的 HTTP(S) 保护网站地址，例如 `https://example.com`。
2. 按需要设置陌生人持续时间与离席容忍时间，点击“开启保护”。开启前需要确认本人在场。
3. 扩展会预先打开保护标签页。**请保留该标签页和监测标签页；另开或切换到同一窗口内的其他标签页浏览。**
4. 触发保护时，扩展依次执行：
   - 保存当前浏览页的网址、标题、时间和触发原因。
   - 关闭当前浏览页。
   - 激活原来的保护标签页并聚焦其窗口，保留该页的加载状态。
5. 每次触发后保护会暂停。在监测页下方的“关闭网页记录”中点击“恢复网页”，可重新打开被关闭的网址；准备好后再次点击“开启保护”。
6. 需要主动结束监测保护时，点击“停止保护”。摄像头预览会继续运行，关闭监测标签页可释放摄像头。

首次使用建议先打开一个普通测试网页，分别测试陌生人入镜、本人离席和网址恢复。

## 工作范围与识别规则

- 保护开启时所在窗口的**当前活动 HTTP(S) 标签页**，不会批量关闭其他标签页或其他窗口。
- 原保护标签页、监测标签页和浏览器内部页面不会作为当前浏览页被关闭。其他标签页即使网址与保护网站相同，也按当前浏览页处理。
- 如果原保护标签页已被关闭，触发时仍会记录并关闭当前浏览页，但无法切回保护页，且不会临时新开页面；监测页会报告错误，需要重新开启保护来准备保护标签页。
- 使用 **YuNet** 检测人脸与五点关键点，经过对齐后由 **SFace INT8 / MobileFaceNet** 提取身份特征，使用本地 ONNX Runtime Web / WASM 推理。模型权重合计约 10.13 MB。
- 每张脸需至少两个录入样本支持匹配。取第二高的余弦相似度作为决策依据，原始余弦低于 **0.45** 判为陌生人，对应界面匹配分低于 **70**。
- 匹配分是决策刻度，**不是身份概率或准确率百分比**。界面同时显示原始余弦值。检测到但无法验证身份的人脸也会触发保护。
- 实际响应时间还包括采样、模型推理和浏览器调度。大角度、低头遮挡、逆光等情况仍可能误判，需在实际摄像头环境中验证；不提供活体防伪检测。
- 监测页面需要保持打开，可切到其他标签页。系统休眠、浏览器冻结、退出或后台调度延迟时，不能保证即时保护；浏览器重启后需要重新开启。
- 恢复记录保存的是网址，不保存页面快照；未保存的表单内容、滚动位置和页面运行状态无法保证恢复。

## 隐私与权限

摄像头画面与人脸识别均在本机处理，不上传图像、视频或面部特征，也不保存照片、录像。面部特征向量、设置和网址记录保存在本浏览器的扩展本地存储中，不使用云同步；保护状态保存在浏览器会话存储中。

可以通过“删除面部特征”和“清空记录”删除相应数据。面部特征未额外加密，具有本机访问权限的人可能读取浏览器存储。访问保护网站或恢复网页仍会产生该网站正常的网络请求。

扩展请求 `storage`、`tabs` 和 `alarms` 权限，分别用于保存设置与记录、管理保护和浏览标签页、检查监测心跳；摄像头访问另由浏览器征求授权。

## 文件说明

```text
.
├── manifest.json       扩展配置与权限
├── background.js       保护标签页管理、关闭记录与异常保护
├── monitor.html        监测与设置页面
├── monitor.js          摄像头、范围选择、录入与检测流程
├── style.css           页面样式
├── core.mjs            特征匹配、评分与样本校验
├── face-engine.mjs     检测、对齐与身份特征提取
├── models/             ONNX 模型、来源校验记录与模型许可证
└── vendor/             ONNX Runtime Web / WASM 与许可证
```
